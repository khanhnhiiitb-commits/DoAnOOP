bán hàng, khách hàng và nhân viên một cách hiệu quả.

## Hướng Dẫn Clone & Cài Đặt Đồ Án OOP - Quản Lý Siêu Thị  
Link github: https://github.com/khanhnhiiitb- commits/DoAnOOP 
1. Môi trường yêu cầu (Prerequisites)
Trước khi bắt đầu, máy tính của bạn cần được cài đặt sẵn:
Visual Studio 2022 (Đã check chọn gói .NET desktop development).
Git (Để clone source code).
2. Hướng dẫn tải Code về máy (Clone Repository)
Bạn có thể tải code về bằng 1 trong 2 cách sau:
Cách 1: Dùng Terminal / Command Prompt (Khuyên dùng)
Mở thư mục bạn muốn lưu code trên máy tính (VD: D:\HocTap\).
Click chuột phải, chọn Open in Terminal hoặc mở Git Bash.
Chạy câu lệnh sau: git clone https://github.com/khanhnhiiitb/DoAnOOP.git
Đợi quá trình tải hoàn tất, bạn sẽ thấy thư mục DoAnOOP xuất hiện.
Cách 2: Dùng giao diện của Visual Studio
Mở Visual Studio lên.
Ở màn hình khởi động, chọn Clone a repository.
Dán đường link https://github.com/khanhnhiiitb/DoAnOOP.git vào ô Repository location.
Chọn đường dẫn lưu file ở ô Path và nhấn Clone.
3. Thiết lập và Chạy phần mềm (Build & Run)
Mở thư mục code vừa tải về, nhấp đúp vào file Solution có đuôi .sln (Ví dụ: ChuongtrinhQuanlybanhangsieuthi.sln) để mở project bằng Visual Studio.
Chờ Visual Studio tải xong cấu trúc thư mục (nhìn thanh trạng thái bên dưới cùng màn hình báo chữ Ready).
Nhấn tổ hợp phím Ctrl + Shift + B để Build project, giúp hệ thống kết nối các file lại với nhau.
Nhấn phím F5 (hoặc nút ▶ Start màu xanh lá) để chạy phần mềm!
